# 项目文档

这里是 ReqWS 文档的唯一总入口；先按分类定位索引，再阅读与当前任务相关的文档。

## 分类索引

| 分类 | 说明 |
|---|---|
| [需求与变更](changes/README.md) | 按需求聚合需求说明、技术方案、测试材料和交付记录。 |
| [文档规范](standards/README.md) | 约定文档何时创建、如何命名、索引怎样同步，并提供精简模板。 |
| [历史参考](reference/README.md) | 保存冻结的原始方案和交接资产，不代表当前实现。 |

## 搜索顺序

1. 阅读本页和相关分类的 `README.md`，确认文档状态和权威性。
2. 按业务词、需求标识或模块名搜索分类索引。
3. 再搜索正文；涉及实现事实时同时核对代码和测试。

```bash
rg -n -i --glob 'README.md' '<业务词|需求标识|模块名>' docs
rg -n -i --glob '*.md' '<业务词|需求标识|模块名>' docs
rg --files docs | sort
```

`docs/reference/` 只用于追溯历史输入。历史方案与现行文档冲突时，以标记为 `active` 的文档及当前代码、测试为准。

## 维护入口

新增需求或修改行为前，先按[文档规范](standards/documentation-standard.md)判断需要创建或更新哪些材料。文档新增、移动、重命名、删除，或状态与索引摘要发生变化时，必须在同一次变更中更新最近一级 `README.md`；完成前运行 `npm run docs:check`。
