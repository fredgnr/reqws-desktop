## 按任务定位

已知路径或只修正文案时，直接阅读目标章节并确认状态；无需先通读总索引、分类索引和所有正文。需要发现未知需求或判断权威性时，按相关分类及需求索引定位，也可以直接搜索业务词、需求标识、IPC channel 或模块名：

```bash
rg -n -i --glob 'README.md' '<业务词|需求标识|模块名>' docs
rg -n -i --glob '*.md' '<业务词|需求标识|模块名>' docs
```

索引用于导航与判断状态，不是每次编辑的串行阅读关卡。涉及实现事实时核对代码和测试；`docs/reference/` 只用于追溯历史输入。历史方案与现行文档冲突时，以相关 `active` 文档及当前代码、测试复核结果为准，发现冲突要明确说明。

## 维护入口

需求、设计、验收条件或文档结构变化时，按[文档规范](standards/documentation-standard.md)判断需要更新的材料；小修不创建空文档集。文档新增、移动、重命名、删除，或状态与索引摘要发生变化时，在同一次变更中更新最近一级 `README.md` 和受影响入链；文档修改完成后运行 `npm run docs:check`。
