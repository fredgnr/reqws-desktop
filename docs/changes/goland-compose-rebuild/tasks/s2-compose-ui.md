# S2：实现完整 Compose 内容界面

本阶段用同一个生产屏幕完成现有工具窗口功能，并以组件测试保证行为而非复刻 Swing 类层次。

## 输入和所有权

G1 已通过；状态/操作接口、fixtures 和宿主入口已固定。Main 独占 Screen 装配、共享 token、UiState/Action、build 和 Bundle；Worker A/B 各有不相交的组件文件及测试文件，不共同修改通用组件。

组件只接受不可变数据和事件，不能从 composable 获取 Project、访问 service、读 VFS 或执行同步。不得顺带添加仓库生命周期操作和加载配置写入。

## 子任务

| ID | 内容 | 输出与直接验证 |
|---|---|---|
| S2.1 | Worker A 实现摘要、状态和稳定 key 仓库列表，处理空集/长列表/重排。 | 生产组件与 V07、相关 V08 测试；区分选择与加载。 |
| S2.2 | Worker B 实现诊断、同步/打开配置/复制操作和反馈。 | 生产组件与 V08、动作 enabled/真实事件测试；错误与复制反馈共存。 |
| S2.3 | Main 组合屏幕，接主题、文案和键盘/可访问语义；必要时走只读翻译。 | 同一界面明暗/窄宽度/Unicode 样本；V08/V09。 |
| S2.4 | Reviewer 审查 UI 与领域解耦、状态真实性、长文本和焦点；Main 修复后验收。 | G2 记录及旧用例到新语义测试的实际选择器。 |

S2.1 与 S2.2 可并行；通用组件不足时先由 Main 补齐签名再继续。已有文案尽量复用；仅真实 delta 才调用 Translator，UI Worker 不写翻译基线。

## G2 通过条件

V07–V09 组件覆盖通过，测试调用真实生产组件；控件可按语义定位并产生正确事件；同名仓库保持身份、列表重排不串选、长文本不遮挡操作、用户字符串不作 HTML/Markdown 解释。

主题与布局检查不能只断言 testTag 存在；可访问角色和值必须正确。VoiceOver 和真实 IDE 的输入/缩放由 S3 完成，不把独立组件测试描述成系统可访问性已通过。

## 交接

提供组件/测试精确文件、Screen 集成 commit、新增资源 delta（若有）及 V07–V09 报告。旧 Swing 内容不再是新功能开发入口，但在新覆盖和清理门槛满足前不先删测试。
