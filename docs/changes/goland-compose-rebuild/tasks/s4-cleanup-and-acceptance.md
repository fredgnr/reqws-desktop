# S4：删除旧实现并验收唯一候选

本阶段清除被替代的代码和断言，对最终单一 Compose 实现完成候选检查、性能复核和独立审查。

## 输入和所有权

G3 已通过；新覆盖迁移表与旧代码精确删除清单可追踪。Main 串行负责删除、装配、文档与候选；不再安排并行 Worker 修改相关调用方。Reviewer 对固定 commit 仅读审查，修复由 Main 或重新分配的 Worker 完成后再复查。

## 子任务

| ID | 内容 | 输出与直接验证 |
|---|---|---|
| S4.1 | 核对旧 Panel、自绘/tooltip/list renderer 与 UI dispatcher 的所有消费者。 | 最终删除清单；每个旧测试说明保留/改写/删除理由及替代证据。 |
| S4.2 | 原子删除旧生产实现、旧专属断言及无消费者工具；更新调用方。 | 编译与直接测试；V12，无开关、no-op adapter、死入口或双 UI。 |
| S4.3 | Main 执行完整保留门禁、新 UI 测试、产物检查并生成确切 ZIP。 | `check:goland`、新任务、V01/V02/V12 与非零测试结果。 |
| S4.4 | 对该候选执行必需本机检查和与 S0 同环境的性能对比。 | V03/V06/V09/V10/V11；关闭后无活动监听/任务，资源增长有复测依据。 |
| S4.5 | Reviewer 查最终 commit/报告/ZIP 一致性及边界，Main 修复后重跑受影响项。 | 独立审查结论与所有阻塞问题闭环，不借旧候选报告。 |
| S4.6 | 同步当前开发/使用/测试说明与索引，记录各阶段结果和真实缺口。 | `docs:check`、最终 diff、G4 与交接说明；仍不包含发布。 |

## G4 通过条件

全部必需 V-ID 对最终候选成立；没有 P0/P1 或其他阻塞问题。旧 UI 及其专属机制已删除，保留 IntelliJ 宿主边界；测试/诊断控制通道和 standalone 库不进入 ZIP；独立审查真实执行；性能预算通过，非确定噪声已复测。

未执行必需系统验收、授权阻塞或环境缺失均应记录并保持 G4 blocked。只要生产代码、依赖、SDK、测试 harness 或候选 ZIP 改变，复核证据适用性并重跑对应项；签名后的候选不能直接借用签名前宿主证据。

## 文档和交付

按实际变化更新插件 README、开发指南、IDE 测试标准及兼容政策，不将所有历史文档机械改写。仅将真实被替代的方向标记并链接替代材料，保留原验证记录；本需求包在适当评审/实施节点更新状态，而不是把 draft 批量改成 completed。

交付包含最终 commit、测试/候选说明、改动与删除范围、已知限制和下一步授权边界。回退通过 Git 撤销，不迁移或删除用户工作区。用户未另行授权时，不合并、安装日常 IDE、打 tag、创建 Release 或提交 Marketplace。
