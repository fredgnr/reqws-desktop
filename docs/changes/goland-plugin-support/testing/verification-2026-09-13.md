# GoLand 修复交付与验证报告

本文保留原 GoLand 插件交付的结论、验证范围与限制摘要，详细过程和校验台账由固定 Git 历史承载，不作为语言解耦候选的执行记录。

## 1. 交付结论

原报告的交付结论为 **GO**，对应当时的插件实现与约定范围；sleep/wake 为用户明确跳过的 **USER_SKIPPED**，不算 PASS。本次仅精简记录，没有重新执行原测试，也没有改变原结论。

完整来源见[原报告的固定 Git 快照](https://github.com/fredgnr/reqws-desktop/blob/92cc4290da071035d4d284ee27859331c4b4bf41/docs/changes/goland-plugin-support/testing/verification-2026-09-13.md)。此链接定位历史文档，不把该文档提交冒充实际执行测试的源码版本；原候选、构建及执行归属以原报告和 [PR #3](https://github.com/fredgnr/reqws-desktop/pull/3) 为准。

## 2. 修复内容

原修复涵盖 manifest 外部替换监听、项目排除项与 live 范围、旧 Go registry 补偿、状态发布与有界重放、首次 metadata 等待/超时、取消恢复、诊断反馈、Desktop 仓库选择、同步追踪与长名称提示。插件保持 Desktop 唯一 manifest writer、VCS 只读及用户配置保护。

Go registry、Go package 配置等属于原实现行为，后续已由[语言解耦规范与方案](../../ide-plugin-language-decoupling/README.md)取消相应承诺，不得从本归档恢复那些新验收门禁。

## 6. GO 结论与保留边界

sleep/wake 保留 USER_SKIPPED。生产构建没有受控取消 GUI 注入入口，该条件式 GUI 项不适用，取消/重试仍有当时的真实平台回归；不能记为已完成 GUI 注入。Safe Mode 原地信任后可能需按 IDE 原生提示关闭重开。

原报告将外部 `.gitignore` 写入归于原生 VFS，不声称整个 IDE 对外零写入。有限 JFR、进程和资源采样不证明无限期性能、零网络或捕获全部瞬态事件；部分早期临时材料已缺失，保留这一限制。
