## 核心调整

保留现有 `guides / standards / changes / reference` 和逐级 README 导航，增加少量当前架构契约的稳定归属。根索引与上级 README 只帮助选择下一站，不再复述阶段通过数字。当前规则、待实施提案、候选证据与历史输入分开标识；先迁出仍有效的事实，再降低旧方案的默认检索权重。

真正的渐进读取采用“描述筛选 → 摘要和目录 → 指定章节 → 必要契约与源码”。HTML 折叠只服务网页阅读，不算减少模型输入。先完成文档归属试点，再实现可测试的本地读取命令，不引入向量数据库、MCP 服务或提交到 Git 的全量生成索引。
