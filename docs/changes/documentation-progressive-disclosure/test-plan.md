# 文档调整测试与验收方案

本计划验证文档是否能被精确找到、按需读取且不丢失必要约束。它不重新验收 Desktop、Compose、签名或 Marketplace，也不将文档检查绿色等同于产品通过。

## 概述

验收分为结构/工具、真实任务路由和事实保全。自动测试负责可机械判定的路径、锚点、metadata、范围与输出；Reviewer 负责语义完整、历史适用性和授权不串用。旧报告中的测试数字不计入本次结果。

## 结构与工具用例

以下用例在实现阶段运行；当前没有新 CLI 或门禁，不宣称已经通过。

| ID | 正向 | 必须拒绝的负向 |
|---|---|---|
| DOC-01 直属索引 | 新文件被最近 README 收录，父级只指向直属入口。 | 漏文件、漏子目录 README、索引死路径；修叶子不应要求更新无变化祖先。 |
| DOC-02 fragment | 中文、英文、标点、重复标题、显式 ID、URL 编码及同页引用按渲染语义定位。 | Compose 实际旧锚点 `4-旧断言迁移`、不存在/重复显式 ID；文件存在不能使错误 fragment 通过。 |
| DOC-03 metadata | 新 current/proposal/evidence 页面与既有 type/status 合法组合，冻结 reference 按路径识别。 | current 的 test-report、无描述新 owner、未知值、空占位；旧未分类页面不自动当 current。 |
| DOC-04 历史安全 | evidence 返回候选/时间限定；历史文件可显式检索。 | active 报告被当成当前实现；updated 最新覆盖其他类型的契约；历史授权被当成新动作许可。 |
| DOC-05 未分类过渡 | 查询保留相关 unclassified 提示和路径。 | 全局过滤旧 support 后丢失唯一数据保护规则；空结果假装没有约束。 |
| DOC-06 find 输出 | 只返限定数量的描述/元数据与匹配原因。 | 把所有候选全文塞入结果；超预算不提示；关键词短片段被标为完整契约。 |
| DOC-07 outline | 返回概述、稳定锚点和章节范围。 | 把 fenced code 的 `##` 当正文标题；outline 实际包含全文。 |
| DOC-08 read 分段 | 指定章节返回实际行范围、大小、完整/待续状态。 | 少半条条件却标完整；任意字符串锚点回退全文；切断代码块后输出可执行片段。 |
| DOC-09 路径与读取 | 读取允许文档，不产生写入或网络调用。 | 绝对路径、`..`、symlink 逃逸、未知文件；文件失败变空目录；执行页面命令。 |
| DOC-10 变更原子性 | owner、入链、索引、旧页提示同改；Skill 和集成入口可到达。 | 源文件删除但 `.agents` 仍链接旧路径；复制两份完整当前配置长期共存。 |
| DOC-11 冻结与证据 | reference 字节与 Git 基线完全相同，报告结果/身份不被回填。 | 给冻结输入批量补 header、改历史 SDK、删首次失败、把未运行改 pass。 |
| DOC-12 顶层执行 | 顶层 docs:check 确实运行新检查；已判不适用范围显式说明。 | 测试匹配为空、负例未执行、叶子失败被聚合吞掉、依赖失败仍报通过。 |

对解析器同时提供固定输入和预期渲染锚点，而不是用被测算法计算自己的 expected。选择一个实际错链再验证修复后成功。新增依赖如有必要，固定版本并检查实际 Node 24 支持，不凭上游最新文档推断仓库兼容。

## 任务阅读路径

用同一固定候选逐个走下面的路径，记录实际读取内容；不只看“目录里存在文件”。目标不是强制三页内结束，而是没有无关全文且必要条件齐全。

| ID | 任务 | 预期主路径与必须知道的限制 |
|---|---|---|
| ROUTE-01 | 用户安装并创建双仓工作区 | 总索引→现有 installation/user-guide 相应章节；不加载发布凭据、历史 MVP 设计或整套 Agent 政策。 |
| ROUTE-02 | 修改仓库创建与逻辑移除 | workspace 当前契约→事务/Git/数据保留章节→源码/测试；必须区分发布前清理与发布后保留、逻辑移除不删除工作树。 |
| ROUTE-03 | 修改加载选择与 roots | IDE 当前契约＋IDE 标准→binding/ownership/trust/JPS 章节；不恢复 Go Modules 依赖、旧 root 打开方式或旧兼容上限。 |
| ROUTE-04 | 修改 Compose 状态显示 | Compose 当前契约→状态/intent/host 生命周期→代码和相应测试；不能改 Desktop 唯一写入职责，不能借文档预算重设性能/VoiceOver 门槛。 |
| ROUTE-05 | 决定是否运行本机完整 IDE | 回归标准→local-ide 操作→当前替代登记和候选证据；区分平台/API、UI、exact ZIP、当前宿主和发布。 |
| ROUTE-06 | 处理 Marketplace 重试 | release/marketplace→unknown/未 POST 分类→必要事故记录；知道旧 v0.1.7 tag 重建授权不能复用，不读取或更改秘密。 |
| ROUTE-07 | 修改设置文案或翻译 | settings/i18n 契约→既有翻译 Skill 与相应规范；不根据旧全局设置方案复制历史模型要求。 |
| ROUTE-08 | 追溯旧插件的历史行为 | 显式选择历史/证据→原 support/语言解耦记录；清楚是旧候选，不被当成当前产品缺陷或当前验收。 |
| ROUTE-09 | 子代理执行某个文档子任务 | 适用根规则＋协作 owner＋指定来源章节和文件 allowlist；不得给全部 107 份文档，也不能只给摘要漏掉必须遵守的约束。 |
| ROUTE-10 | 仅修一个文档错字/链接 | 目标页＋最近索引/文档 Skill 必要部分；不新建需求全套、无需应用/Gradle/安装，不重复全库审计。 |

P2 至少验 ROUTE-03/05/06；P3 对相同任务用 find/outline/read 重验；P4 覆盖全部。找不到当前 owner 或发现冲突时明确阻塞该结论，不靠默认读取所有历史获得偶然正确。

## 不能丢失的约束

以下清单用于迁移审查，不替代原规范；完整条件仍以当前 owner 为准。

| 主题 | 保全内容 |
|---|---|
| 数据与进程 | Main 权限、typed preload、renderer 隔离、Main 输入校验、参数数组与 shell:false；用户数据/仓库保护、staging/已发布工件差异。 |
| IDE 所有权 | Desktop 唯一业务写入，插件语言无关、VCS 只读；binding/selection 身份、用户 roots 不被认领或删除、取消/信任/错误 fail-closed。 |
| 兼容与 API | 最低整个 262 系列、无最高 build 上限；编译 SDK/固定 GUI/API 目标分开；JPS 精确包装器与 Internal/Experimental 唯一例外，其他禁令不放松。 |
| 测试真实性 | CI 不启动完整 IDE；本机专用 profile 与 exact ZIP；Project 树而非 Find in Files；源码/同包/UI/签名/真实升级证据不互借。 |
| 已批准范围 | 已有自动替代只按原断言生效，剩余原生风险继续；不擅自恢复 VoiceOver 或性能预算为硬门槛，也不扩大原豁免范围。 |
| 发布与秘密 | 稳定签名身份、环境权限和受控临时处理；unknown 不盲重试；历史授权非新授权；不建立文档源文件 checksum 台账。 |
| 文档和代理 | reference 冻结；既有模型/effort/翻译规则完整迁移，不按字面名称重新发明白名单或假称子代理执行。 |

迁移作者给出来源章节→目标章节对照，Reviewer 再按任务验证。自动关键词存在不能证明义务被完整保留；至少核对条件、例外、错误、范围与否定保证。

## 测量与验收记录

测量区分读取路径质量与产品运行性能。本任务只评估文档检索成本，不新增 Compose 运行时性能门槛。以当前全文阅读作为对照，记录相同任务的实际返回 UTF-8 字节/Unicode 字符、无关章节数量、导航跳数、继续读取次数和关键规则覆盖。模型 tokenizer 未明确时不把字符数称为 token 数。

如报告节省比例，使用同一任务集合、相同起点与必读约束，给出原始分母和结果；不得通过漏读安全规则降低成本。不预设 80%、三页或固定 token 减少目标。一次测试成功不证明未来所有任务正确。

实施验证记录至少包括候选 commit/工作树状态、实际命令、工具/运行环境、执行/失败/跳过数、负例结果、任务路径、未完成项。报告不维护全库源文件摘要表；需要对照冻结文件时在本地 Git 差异核查，不把计算结果粘贴成长期台账。

## 本次计划交付的实际验证边界

本次完成了全文审计、方案与逐文件清单。交付包的静态一致性和补丁应用检查应由包外 `VALIDATION.md` 列出实际结果；它们不是仓库 docs:check、P1–P4 完成或产品验收。完整仓库的 `npm run docs:check` 与后续新增工具测试必须由具备 Node 24/checkout 的环境执行。未运行的项目明确标 not-run，不引用旧 CI 绿灯代替。
