# 文档模板

这些模板是最小骨架，应按实际复杂度增删章节；不要为了填模板而制造无内容文档。

| 模板 | 状态 | 用途 |
|---|---|---|
| [需求说明模板](requirement.md) | active | 明确背景、范围、业务规则和可验证验收条件。 |
| [技术方案模板](technical-design.md) | active | 记录现状、决策、跨层影响、风险和实施顺序。 |
| [测试方案模板](test-plan.md) | active | 定义验证范围、场景、环境、证据和退出标准。 |
| [交付记录模板](delivery.md) | active | 汇总交付范围、迁移/回滚、验证结果和已知限制。 |
